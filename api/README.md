# Gemini Proxy 2 installation

Upload `query-fanout-auditor.js` into the `api` folder of the existing `gemini-proxy-2` GitHub repository.

The final repository path must be:

`api/query-fanout-auditor.js`

The proxy project must already contain `@google/genai` in `package.json` and `GEMINI_API_KEY` in its Vercel environment variables.
